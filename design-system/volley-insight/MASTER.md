# Volley Insight 디자인 시스템 (MASTER)

> **2026-11-11 전면 재디자인(Hallmark · Sport 테마).** 아래 "현재 기준"이 우선한다. 그 밑의 예전 표(색상 토큰·글꼴)는 기록으로만 남긴다.
> 지금까지 적용된 화면: 공통 틀(머리글·바닥글·공용 클래스)과 홈. 나머지 화면은 토큰만 따라 바뀌었고 구성은 아직 예전 그대로다.

## 현재 기준 (Sport: 경기 기록지)

- **토큰 파일:** `frontend/src/tokens.css`(색·글꼴·간격), `frontend/src/base.css`(기본 규칙), 공용 클래스는 `App.vue`. 색·글꼴 값은 tokens.css에만 쓴다.
- **색:** 차가운 종이색 바탕(`--color-paper` 3단계), 짙은 남색 잉크(`--color-ink`), 강조는 형광 라임(`--color-volt`) 하나.
  라임은 항상 "채움 + 잉크 글자"로만 쓴다(글자색·가는 줄로 쓰지 않는다): 이긴 쪽 스코어, 선택된 탭, 주 버튼, 실시간 표시, 지금 메뉴의 밑줄.
  홈팀 = 잉크, 원정팀 = 중간 회청색(`--color-away-tone`). 좋음/나쁨은 초록/빨강 + 부호.
  팀 이름 글자는 팀 컬러(`--team-{코드}`, 엠블럼 대표색을 대비 4.5:1까지 어둡게 한 값): 팀 링크(`/teams/코드`)는 자동, 링크가 아닌 이름은
  `data-team="코드"`. 짙은 바탕과, 홈/원정 색이 그래프와 짝을 이루는 실시간 화면에는 쓰지 않는다. 경기 카드에서 진 팀은 회색.
- **글꼴:** 표제·팀 이름·스코어 = Saira Condensed 800(숫자·영문) + Black Han Sans(한글). 본문 = Pretendard. 시각·기록 숫자 = JetBrains Mono. 모두 SIL OFL 1.1(무료·상업 이용 가능). 글꼴을 바꿀 때는 자유 라이선스인지 확인하고 `frontend/FONT_LICENSES.md`에 적는다.
- **면:** 상자·그림자 없음. 굵은 줄(2px)로 구역과 표를 열고 닫고, 가는 줄(1px)로 행을 나눈다. 타일은 굵은 줄 아래 옅은 칸(`--color-paper-2`). 둥글기 4px, 알약 모양 없음.
- **머리글:** 잉크색 띠. 진행 중 경기 타일도 잉크 바탕(전광판).
- **글:** 링크 글자에 화살표를 붙이지 않는다("전체 일정 보기"). 가운뎃점으로 정보를 잇지 않는다. 장식용 점을 쓰지 않는다.
- **움직임:** 등장 애니메이션 없음. 상태와 데이터가 바뀔 때만 움직인다.
- **순위표 구간:** 순위 칸을 잉크로 채움 = 포스트시즌권, 옅게 채움 = 준플레이오프권 + 표 아래 범례.

모든 화면의 기준이다. 화면별 예외는 `pages/<화면>.md`에 두고, 있으면 그 규칙이 우선한다.
`ui-ux-pro-max` 스킬 검색 결과 중 이 서비스에 맞는 것만 골라 조합했다(2026-11-03).

## 규칙
- **접근성:** 본문 대비 4.5:1 이상, 모든 링크·버튼·선택 상자에 `:focus-visible` 테두리, 토글 버튼은 `aria-pressed`, 차트는 `role="img"` + 요약 문장.
- **터치:** 터치 기기(`pointer: coarse`)에서 탭·선택 상자 높이 44px 이상.
- **로딩:** 빈 화면이나 "불러오는 중" 글자 대신 자리를 유지하는 스켈레톤 + `aria-busy`.
- **표:** 넓은 표는 표 안에서만 가로 스크롤(`.table-wrap`), 첫 열 고정. 정렬 가능한 표는 `aria-sort`.
- **차트:** 색만으로 구분하지 않는다(값·부호·라벨을 함께). 점수 흐름은 리드 변경 횟수·최다 연속 득점을 문장으로도 보여준다.
- **아이콘:** 이모지를 쓰지 않는다. 필요하면 SVG.
- **구역과 카드(2026-11-11):** 카드 안에 카드를 넣지 않는다. 경기 카드처럼 카드 목록이 들어가는 구역은 테두리 없는 `.section` + `.section-head`를 쓰고, 표·글 목록은 `.card`를 쓴다.
- **색 띠 금지:** 카드·표 행 옆의 굵은 색 테두리(`border-left`)를 쓰지 않는다. 순위표의 포스트시즌 구간은 순위 숫자 앞의 점(`tr.po`/`tr.semi` + `td.rank`)과 표 아래 범례(`.zone-legend`)로 알린다.
- **반응형 기준:** 머리글은 900px 이하에서 두 줄(로고+메뉴 / 검색+로그인), 메뉴는 줄바꿈 없이 안에서 옆으로 민다. 두 칸 배치(`.grid-2`)는 760px 이하에서 한 칸. 경기 카드 격자는 `minmax(min(100%, 300px), 1fr)`로 1~3열.
- **브라우저 기본 표면:** 글자 선택 색, 스크롤바, 입력 커서도 토큰 색을 따른다(`App.vue`).
- **출처:** 모든 화면 하단에 KOVO 출처 (WEB-14).

## 모션 (2026-11-06, `frontend/src/motion`, 외부 라이브러리 없음)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--dur-fast` | 160ms | 호버, 누름, 색 |
| `--dur-base` | 240ms | 탭 선택 표시, 작은 이동 |
| `--dur-slow` | 420ms | 행 자리 바꿈, 막대 크기, 점수 숫자 |
| `--dur-enter` | 520ms | 스크롤로 들어오는 내용 |
| `--dur-chart` | 750ms | 차트가 그려지며 등장 |
| `--ease-out` / `--ease-in-out` / `--ease-spring` | 감속 / 두 곳 사이 이동 / 작은 튀어오름(점·아이콘만) | |

도구: `useTween`(숫자가 새 값으로 미끄러짐), `useInView`, `useFlash`, `AnimatedNumber`, `RollingNumber`(자릿수가 굴러가는 점수),
`v-reveal`(스크롤 등장, 형제끼리 45ms 차이), `v-glider`(탭 선택 표시가 미끄러짐), 페이지 전환(`page`), 목록 이동(`row`, `item`), `swap`, `.lift`.

규칙:
- 움직임은 데이터나 위치가 바뀐 것을 알려줄 때만 쓴다. 장식용 반복 애니메이션은 없다(로딩 스켈레톤과 실시간 점만 반복).
- transform·opacity만 움직인다. 너비·높이를 애니메이션하지 않는다(막대는 `scaleX`).
- 첫 화면 자료(실시간 첫 스냅숏 등)는 그냥 나타나고, 그 뒤의 변화만 움직인다.
- 숫자가 움직여도 화면 읽기 프로그램에는 최종 값 하나만 읽힌다(움직이는 숫자는 `aria-hidden`).
- 차트 상호작용은 마우스·키보드 둘 다: 좌우 화살표로 값, Elo 차트는 끌어서 확대 + `+`/`-`/`0` 키와 버튼, 요약 항목에 올리면 차트에 표시.
- `prefers-reduced-motion: reduce`이면 모든 움직임 없이 최종 상태를 보여준다(내용이 숨겨진 채 남지 않는다).
- 다시 불러오는 동안 이전 값은 흐리게(`.busy`) 남기고, 새 값이 오면 그 자리에서 미끄러지게 바꾼다(순위표, 예측 검증, 일정).
- 기준선이 있는 막대(리그 평균 비교, 선수 유형)는 기준선에서 양쪽으로 자란다. 여러 줄이면 줄마다 50~70ms씩 늦게.
- 차트·막대의 항목에 올리면(또는 포커스하면) 문장으로 풀어 준다(세트 스코어 확률, 레이더 축, 점수 흐름 요약). 터치 기기에서는 안내 문구를 숨긴다.
